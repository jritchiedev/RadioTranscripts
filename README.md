# Radio transcripts

QR2 radio transcript catalog, grouped into readable passages by station and frequency and refreshed every 15 minutes while the finite recording campaign is active.

Open `index.html` using GitHub Pages. The page loads the adjacent catalog manifest and JSON shards. Plain-text, CSV and complete JSON downloads are generated in the browser.

Times are approximate local stream receipt times in MDT, CDT or UTC. Buffering and local advertisement replacement may differ from terrestrial broadcasts. Original wording is uncorrected ASR. Only identified song-lyric segments are excluded; ambiguous speech is retained. New files awaiting classification are counted on the page.

Original audio stays in the local recording workspace. The catalog shows source filenames and original segment offsets for verification.
